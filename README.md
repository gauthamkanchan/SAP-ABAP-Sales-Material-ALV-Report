# Sales & Material Information ALV Report

## Project Overview

A custom SAP ABAP ALV report developed to retrieve and display
sales and material information based on Sales Document Number.

## Technologies

- SAP ABAP
- Open SQL
- Internal Tables
- Work Areas
- Selection Screens
- ALV Reporting

## SAP Tables Used

- VBAK – Sales Document Header Data
- VBAP – Sales Document Item Data
- MARA – Material Information
- MARD – Material Information
- MAKT – Material Description

## Features

- Sales Document Number based selection
- Sales document data retrieval
- Material information retrieval
- Internal table processing
- READ TABLE processing
- ALV-based output display
- Field catalog configuration

## Output Fields

- Sales Document Number
- Sales Document Type
- Item Number
- Material Number
- Material Type
- Plant
- Material Description
